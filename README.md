# Primeiro Teste de API com Playwright + TypeScript

## Objetivo

Este projeto tem como objetivo realizar meu primeiro teste automatizado de API utilizando Playwright com TypeScript, validando respostas HTTP, status code e estrutura básica do retorno da API.

---

## Tecnologias Utilizadas

* Playwright
* TypeScript
* Node.js
* npm

---

## Pré-requisitos

Antes de iniciar, é necessário ter instalado:

* Node.js (versão LTS)
* npm

Verifique com:

```bash
node -v
npm -v
```

---

## Instalação

1. Clone o repositório:

```bash
git clone https://github.com/BarbaraFe/test-api.git
```

2. Acesse a pasta do projeto:

```bash
cd api-playwright-test
```

3. Instale as dependências:

```bash
npm install
```

4. Instale o Playwright:

```bash
npm init playwright@latest
```
